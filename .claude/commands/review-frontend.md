# 前端代码审查

审查 frontend/src/ 目录下的所有代码，检查以下问题：

1. **组件设计** - 组件是否过大、是否需要拆分、props 是否合理
2. **状态管理** - useState/useEffect 使用是否正确、是否有内存泄漏风险
3. **用户体验** - 加载状态、错误提示、空状态处理是否完善
4. **性能优化** - 是否有不必要的重渲染、图片加载是否优化
5. **样式一致性** - TailwindCSS 使用是否规范、响应式是否到位

输出格式：
- 问题严重程度（Critical/High/Medium/Low）
- 文件位置和行号
- 问题描述
- 修复建议和代码示例
