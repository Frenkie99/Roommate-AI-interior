# 行业研究：AI 图像产品如何做评测（指导本项目 grader 设计）

> 来源：2026-06-30 一次深度研究（5+ 路并行检索、27 个来源、对抗式核实 25 条关键结论、2 条强主张被证伪）+ 针对性补充检索。
> 用途：回答「该不该花钱上 VLM-as-judge」并**直接指导本项目评分器（grader）设计**。配套：`READINGS.md`（方法论阅读）、`VISION_JUDGE_DESIGN.md`（落地蓝图）。
> 阅读纪律同 READINGS：带审视读，强主张若被对抗验证否决则明确标注，不外推。

---

## 0. 一句话结论

对「毛坯房→精装效果图」这类**必须保结构 + 遵循指令**的图像编辑产品，**花钱上 VLM-as-judge 是有充分文献支撑、值得做的方向**，且成本极低（实测 gemini-flash 一次完整评测 ≈ $0.05）。但有三条「怎么做」是硬约束，直接改写我们当前 vision_judge 的设计。

## 1. 被核实的关键事实（带出处）

| # | 结论 | 出处 | 置信 |
|---|---|---|---|
| F1 | **MLLM 当评委：成对比较与人类高度一致；直接打标量分/批量排序则显著偏离人类**，连 GPT-4V 都有偏见/幻觉/不一致 | MLLM-as-a-Judge, ICML 2024, arXiv 2402.04788 | 高 |
| F2 | **VQA 式评测**（把对齐拆成 Yes/No 问答，TIFA / VQAScore）与人类相关性**优于 CLIPScore/PickScore/HPSv2/ImageReward**；GenAI-Bench 实测按 VQAScore 重排比这些奖励模型**有效 2–3 倍** | VQAScore ECCV 2024 (2404.01291)、TIFA (2303.11897)、GenAI-Bench (2406.13743) | 高 |
| F3 | **CLIPScore 文本编码器像「词袋」**，会把「马吃草」和「草吃马」混为一谈，对"物体-属性-关系"组合的复杂指令给不出可靠分 | CLIPScore EMNLP 2021；VQAScore 复述 | 高 |
| F4 | **视觉生成/编辑任务上，成对(pairwise)一致地优于点评(pointwise)**；但成对有 O(N²) 成本、位置偏见（需正反各跑）、且可能放大偏好偏差 | GenArena (2602.06013)、Pairwise-or-Pointwise (2504.14716)、Comparative Trap (2406.12319) | 中-高 |
| F5 | **VIEScore（最贴本场景：条件图像合成/编辑评测）**用 MLLM 点评、拆成「语义一致性 SC + 感知质量 PQ」两个子分；GPT-4o 与人类 Spearman **≈0.4（生成）、更弱（编辑）**，而**人类之间也只有 ≈0.45** | VIEScore ACL 2024, 2312.14867 | 高 |
| F6 | **结构/几何畸变是公认最难自动评测、相关性最低的维度**（室内 IQA：distortion 0.66 << harmony 0.90）——恰是本产品「承重墙体门窗保真」最在意处 | SA-IQA, 2512.05098 | 中 |
| F7 | **人工成对偏好 → 训 reward model 是被验证的金标准范式**：ImageReward 用 137k 专家成对比较；PickScore 用真实用户偏好；HPSv3 同类 | ImageReward NeurIPS 2023 (2304.05977)、PickScore (2305.01569)、HPSv3 ICCV 2025 | 高 |
| F8 | **图像编辑已有专门 MLLM 细粒度评测框架**（12 因子覆盖 图像保留/编辑质量/指令保真；I2EBench 用 GPT-4V 评高层维度；MagicBrush 用 L1/L2 + CLIP-I/DINO + CLIP-T 但作者承认整体质量自动指标与人类对不齐） | 2602.13028、I2EBench (2408.14180)、MagicBrush (2306.10012) | 中-高 |
| F9 | **成本可压一两个数量级**：K-Sort Eval 用 gemini-2.0-flash，一次完整评测 ≈$0.05，K 路排序采样让 91% 的图 90 次比较内完成（vs GenAI-Bench 1600 次）；VQAScore 的**开源 CLIP-FlanT5 甚至超过依赖 GPT-4V 的最强基线**（省钱路径存在） | K-Sort Eval (2602.09411)、VQAScore (2404.01291) | 中-高 |

**被对抗验证否决的强主张（不可信，记录以防误用）：**
- ❌「GPT-4V 评委可替代人工评测」（DEsignBench 2310.15144 自称，独立核实 **0-3 否决**）。→ VLM judge 是**放大器，不是人的替代**。
- ❌「I2EBench 的 GPT-4V 评委与人类在所有维度显著正相关」（核实 1-2 未通过）。→ 只能说"编辑评测已采用 GPT-4V 评委"，不能说"它各维都准"。

**盲区（诚实交代）**：没扒到 RoomGPT / InteriorAI / 美间等**直接竞品的内部评测方法**——商业产品基本不公开。我们拿到的是学术界 + 通用文生图团队的公开方法（同类产品背后用的同一套方法论），但"某竞品私下怎么做"是查不到的黑盒。

## 2. VQA 还是成对？——并存，按维度分工（本项目定调）

「VQA」与「成对」不在同一轴：**成对 vs 点评**=比较协议；**VQA vs 标量**=提问方式。VQA = 点评 + 拆成是非题。二者各擅长不同维度，故**并存**：

| 维度 | 性质 | 协议 | 提问方式 | 依据 |
|---|---|---|---|---|
| 指令遵循 + 结构保真 | 客观、可拆是非题 | 点评 | **VQA**（逐条 Yes/No 加总） | F2/F3：VQA 拆解 > 标量 |
| 美学质量 | 主观、难拆是非题 | **成对 A/B** | 「哪张更美」 | F4：视觉质量上成对 > 点评 |

**关键洞见（F5）**：VIEScore 用「点评 + 拆子分」就到 ≈0.4（接近人类上限 0.45）。所以**病不在"点评"，在"holistic 单一标量"**；点评只要拆维度 + 给 rubric（即 VQA 思路）就可信。

**本项目落地：**
- **日常绝对评测**（「这张够不够好」，无对比对象）→ **VQA 点评**：指令/结构维拆成具体是非题。这是主力。
- **美学维 + 模块五迭代对比**（「改完 prompt 是不是更美」）→ **成对 A/B**：新版 vs 旧版两图比，天然契合迭代闭环；注意正反各跑一次消位置偏见。

## 3. 对本项目 grader 设计的三条修正（行动项）

**修正 1：vision_judge 从「四维 1-5 标量」改为「VQA 拆解 + 成对(美学)」。**
当前 `vision_judge.py` 让模型直接给 structural/aesthetic/instruction 四个 1-5 标量分——正是 F1 说"不可信"的 holistic 标量。改法：
- 指令遵循：拆成产品相关的是非题（「目标风格匹配?房型正确?用户需求满足?有无明显违背?」）。
- 结构保真：拆成是非题（「承重墙位置保留?门窗位置/数量一致?未新增/拆除墙体?」）——但首选仍用非 VLM 的 structural_fidelity（见修正 2）。
- 美学：改成对 A/B（迭代时新旧对比），或对固定参考图比较。
- DoD 不变（vs 85 金标准算对齐度），但**对齐度合理预期 ≈0.4 即接近人类上限，别期待 0.6+**（F5）。

**修正 2：结构维优先用 structural_fidelity（非 VLM），不交给 VLM。**
F6 证：结构/几何畸变是 VLM 最弱维。而我们已有被证可信的 `structural_fidelity`（64×64 布局 SSIM，vs 人工结构金标准 +0.418）。所以**结构维继续用它**，VLM 只补它做不了的美学/指令。
- **可选升级（现在不做，记录备查）**：SAM 掩码 IoU——对毛坯图与效果图各跑一次 SAM（产品已用 Segmind SAM3），比较墙/门/窗区域的交并比(IoU)，比整体 SSIM 更精准盯结构件。**暂不做**：structural_fidelity 已够用；SAM 跑 85×2 张有算力成本（生产仅 900MB 内存）；范围最小化。日后若结构分不够用再评估。人工结构金标准是真值，任何新结构分都拿它验证，无需重标。

**修正 3：人 + VLM 协作流水线，照金标准范式（F7）。**
人工偏好/金标准（我们已有 frenkie 标的 85 条）当真值 → 校准/验证 VLM judge 的对齐度 → 达标才放量 → 结构维与疑难样本人工抽检兜底。**VLM 是放大器不是替代**（被证伪的强主张）。

---

## 4. 省钱实操（若决定花钱跑 VLM judge）

1. **先小批校准对齐度再放量**：用 85 金标准里两极/分层样本先验证 VLM judge 与人工的相关性（我们 vision_judge 的"探价+两极判别力"脚本已是此意）。
2. **图像压分辨率**：结构/美学判断不需原分辨率（我们已缩到 768px）。
3. **采样而非全跑**：K 路排序采样可把评测次数压一两个数量级（F9）。
4. **优先试开源 VQA 模型**：CLIP-FlanT5 等可超 GPT-4V 基线（F9），不一定用最贵闭源；但本产品已有 apiyi Gemini 通道，flash 档 ≈$0.05/次量级也完全可接受。
5. **结构维用免费的 structural_fidelity**，省下的钱花在美学/指令两维。

---

## 5. 一句话总账

业界共识与本项目实践高度吻合：**人工金标准先行 → 把 Judge 当分类器验证对齐 → VLM 放大 → 人工兜底**。我们要做的不是"要不要花钱"，而是把 vision_judge 从"标量打分"升级为"VQA 拆解 + 成对(美学)"，结构维守住已可信的 structural_fidelity。预期对齐度 ≈0.4 即达人类水平，花费 ≈$0.05/次量级。
