# 项目截图存放目录

## 如何添加项目截图到GitHub README

### 方法1：使用现有图片
将您的项目截图保存到此目录，命名为：
- `homepage.png` - 主页/登录页截图
- `generation.png` - 生成效果图展示
- `refine.png` - 精修功能展示
- `chat.png` - RAG知识问答展示

### 方法2：直接在README中引用
```markdown
<div align="center">
  <img src="frontend/public/screenshots/generation.png" alt="生成效果图" width="800"/>
  <p><em>AI生成装修效果图示例</em></p>
</div>
```

### 推荐截图内容
1. **Landing Page** - 首页整体布局
2. **风格选择** - 10种装修风格选择器
3. **图片生成** - 生成过程和结果对比
4. **精修功能** - 框选和局部修改功能
5. **知识问答** - RAG智能回答示例

### 截图技巧
- 使用高清模式截图
- 展示关键功能点
- 保持界面整洁
- 可以添加文字说明
